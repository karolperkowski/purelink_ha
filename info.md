# PureLink UX-8800

Control a PureLink UX-8800 8×8 HDMI matrix from Home Assistant: route inputs to
outputs (as `media_player` or `select` entities), recall and save presets, rename
channels, and monitor per-input signal/HDCP and per-output sync.

Local push-free polling over the device's WebSocket API — no cloud, no account.

Configure from **Settings → Devices & Services → Add Integration → PureLink
UX-8800** with the matrix host and Web UI credentials.
